# App nativa per il Mac — piano di implementazione

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Una `.app` che apre l'editor dei pulsanti già esistente in una finestra propria, riavvia l'agent quando serve, e aggiunge in nativo il drop di un'app dal Finder e la registrazione delle scorciatoie.

**Architecture:** Guscio Swift attorno a un `WKWebView` puntato su `127.0.0.1:8765`. Il guscio non conosce slot, icone né tasti: trasporta fatti grezzi — un percorso, un key code, una risposta HTTP — e li fa interpretare a Python o alla pagina. La logica pura sta in una libreria `MacDeckCore` senza AppKit, così i test girano senza finestra, agent né deck.

**Tech Stack:** Swift 6.3 / SwiftPM / AppKit / WebKit · Python 3.14 / FastAPI / pytest

**Spec:** `docs/specs/2026-08-31-mac-app-design.md`

## Global Constraints

- **Bundle id:** `io.macdeck.app` (distinto da `io.macdeck.agent` del LaunchAgent).
- **Piattaforma minima:** macOS 14 (`.macOS(.v14)` in `Package.swift`).
- **Firma:** ad-hoc, `codesign -s -`. Nessuna notarizzazione, nessun account sviluppatore.
- **Niente sandbox.** L'app legge percorsi di bundle trascinati e invoca `launchctl`.
- **Nessun Bonjour nativo.** Chi parla col deck è l'agent; la presenza del deck si legge solo da `/api/health`.
- **L'app non avvia mai un eseguibile proprio** per far partire l'agent: solo `launchctl kickstart` del servizio esistente. Motivo in §4.1 della spec — il permesso Accessibilità è legato all'eseguibile, e romperlo non dà errore.
- **Endpoint nuovi:** solo loopback (`dependencies=[Depends(require_local)]`), come tutti gli `/api/*`.
- **Lingua:** codice, commenti, messaggi e commit in italiano, come il resto del repo. Nei sorgenti gli apostrofi restano ASCII (`e'`, `piu'`), come già fa il codice esistente.
- **Ogni task finisce con un commit.**

### Scostamento dalla spec, deliberato

La spec §5 elenca i sorgenti Swift tutti sotto `Sources/MacDeck/`. Il piano li divide in **due target**: `MacDeckCore` (libreria pura, testata) e `MacDeck` (eseguibile, glue AppKit). È lo stesso elenco di file, diviso secondo il criterio che la spec §7 chiede — «AppKit fuori dai test». Senza la divisione, un test target che dipende da un eseguibile è possibile ma scomodo, e non ci sarebbe una barriera che impedisca alla logica di scivolare dentro AppKit.

```python
    "control down": "ctrl",
    "option down": "opt",
    "shift down": "shift",

    _CODE_NAMES.setdefault(_codice, _nome)
```

E in fondo al file:

```python
def from_event(key_code: int, modifiers: list[str] | None = None,
               chars: str = "") -> str:
    """Da un evento di tastiera macOS alla combinazione che il dritto legge.

    I key code di NSEvent sono quelli di Carbon, cioe' esattamente quelli di
    KEY_CODES: la tabella non va duplicata in Swift, basta rovesciarla qui.

    `chars` serve per i tasti stampabili, che in KEY_CODES non ci sono: il
    codice del tasto "4" dipende dalla disposizione della tastiera, il
    carattere no.
    """
    clauses: list[str] = []
    for m in modifiers or []:
        clause = MODIFIERS.get(m.lower())
        if clause is None:
            raise InvalidKeys(f"modificatore ignoto: {m!r}")
        if clause not in clauses:
            clauses.append(clause)
    clauses.sort(key=_MOD_ORDER.index)

    nome = _CODE_NAMES.get(key_code)
    if nome is None:
        c = (chars or "").strip()
        if len(c) != 1:
            raise InvalidKeys(
                f"tasto non riconosciuto: key code {key_code}")
        nome = c.lower()

    return "+".join([_MOD_CANON[c] for c in clauses] + [nome])
```

```python
    @app.post("/api/keys-canon", dependencies=[Depends(require_local)])
    def keys_canon(body: dict) -> dict:
        """Da un evento di tastiera alla combinazione canonica.

        Il registratore nativo manda il fatto grezzo — key code e
        modificatori — e la traduzione avviene qui, accanto alla tabella.
        L'app non impara i nomi dei tasti.
        """
        try:
            combo = keymap.from_event(
                int(body.get("keyCode", -1)),
                body.get("modifiers") or [],
                body.get("chars") or "",
            )
        except (keymap.InvalidKeys, TypeError, ValueError) as e:
            raise HTTPException(status_code=422, detail=str(e)) from e
        return {"keys": combo}
```

```python
    def health(request: Request) -> dict:
        """Cosa l'app nativa deve poter dire quando la pagina non puo'.

        Nessuna ricerca del deck qui dentro: si riporta solo quello che
        l'Announcer ha gia' trovato per conto suo. Una seconda opinione

        giro = (s or {}).get("ultimo_giro") or 0.0

            "deck": (s or {}).get("deck"),

            "error": (s or {}).get("ultimo_errore"),
            # secondi dall'ultimo giro, None se non ne ha ancora fatti
            "last_round": (time.time() - giro) if giro else None,
            "accessibility_ok": probe.snapshot().get("accessibility_ok"),
        }
```

```swift
import Foundation

public enum EsitoAvvio: Equatable, Sendable {
    case pronto
    case nonRiparte
    case launchAgentAssente
}

/// La sequenza d'avvio, con il mondo esterno iniettato.
///
/// Stessa scelta che l'agent fa con `executor.py`: i comandi veri stanno
/// fuori, cosi' i test girano senza agent, senza rete e senza dormire.
public struct Avvio: Sendable {
    public var agentRisponde: @Sendable () async -> Bool
    public var launchAgentCaricato: @Sendable () -> Bool
    public var kickstart: @Sendable () -> Bool
    public var attendi: @Sendable () async -> Void
    public var tentativi: Int

    public init(agentRisponde: @escaping @Sendable () async -> Bool,
                launchAgentCaricato: @escaping @Sendable () -> Bool,
                kickstart: @escaping @Sendable () -> Bool,
                attendi: @escaping @Sendable () async -> Void,
                tentativi: Int = 33) {
        self.agentRisponde = agentRisponde
        self.launchAgentCaricato = launchAgentCaricato
        self.kickstart = kickstart
        self.attendi = attendi
        self.tentativi = tentativi
    }

    public func esegui() async -> EsitoAvvio {
        if await agentRisponde() { return .pronto }
        guard launchAgentCaricato() else { return .launchAgentAssente }
        _ = kickstart()
        for _ in 0..<tentativi {
            await attendi()
            if await agentRisponde() { return .pronto }
        }
        return .nonRiparte
    }
}
```

```swift
    private static func launchctl(_ argomenti: [String]) -> (Int32, String) {
        let p = Process()
        p.executableURL = URL(fileURLWithPath: "/bin/launchctl")
        p.arguments = argomenti
        let tubo = Pipe()
        p.standardOutput = tubo
```

```swift
    public init(x: Double, y: Double) { self.x = x; self.y = y }
```

```swift
/// Intercetta i file trascinati prima che ci pensi WebKit.
///
/// E' l'unico punto in cui il percorso del bundle esiste ancora: dentro la
/// pagina un file trascinato arriva come File senza percorso, ed e'
/// precisamente il motivo per cui l'app nativa esiste.
final class VistaWebConDrop: WKWebView {
    override func draggingEntered(_ s: any NSDraggingInfo) -> NSDragOperation {
        percorsi(da: s).isEmpty ? super.draggingEntered(s) : .copy
    }

    override func draggingUpdated(_ s: any NSDraggingInfo) -> NSDragOperation {
        percorsi(da: s).isEmpty ? super.draggingUpdated(s) : .copy
    }

    override func performDragOperation(_ s: any NSDraggingInfo) -> Bool {
        let elenco = percorsi(da: s)
        guard !elenco.isEmpty else { return super.performDragOperation(s) }

        let nellaVista = convert(s.draggingLocation, from: nil)
        let p = puntoViewport(daVistaX: nellaVista.x, daVistaY: nellaVista.y,
                              altezzaVista: bounds.height)
```

```swift
/// L'ordine dell'elenco e' quello canonico che keymap.py si aspetta:

    (1 << 17, "shift"),
```

```swift
import AppKit
import MacDeckCore

/// Un foglio che ascolta i tasti veri e restituisce la combinazione.
///
/// Limite dichiarato: le combinazioni che macOS si riserva (cmd+shift+4,
/// cmd+space) non arrivano mai qui, perche' il sistema le consuma prima.
/// Il pannello lo dice, invece di restare in ascolto per finta.
final class RegistratoreTasti: NSObject {
    private var monitor: Any?
    private var foglio: NSWindow?

    func mostra(su finestra: NSWindow,
                base: URL,
                completamento: @escaping (String?) -> Void) {
        let f = NSWindow(contentRect: NSRect(x: 0, y: 0, width: 380, height: 130),
                         styleMask: [.titled], backing: .buffered, defer: false)
        let t = NSTextField(labelWithString:
            "Premi la combinazione.\n\nAlcune scorciatoie di sistema "
            + "(cmd+shift+4, cmd+space) non arrivano fin qui: per quelle "
            + "scrivila a mano nel campo.")
        t.frame = NSRect(x: 20, y: 45, width: 340, height: 70)
        t.maximumNumberOfLines = 4
        let annulla = NSButton(title: "Annulla", target: self,
                               action: #selector(chiudi))
        annulla.frame = NSRect(x: 270, y: 12, width: 90, height: 26)
        f.contentView?.addSubview(t)
        f.contentView?.addSubview(annulla)
        foglio = f

        monitor = NSEvent.addLocalMonitorForEvents(matching: .keyDown) { ev in
            let mods = modificatori(daFlag: ev.modifierFlags.rawValue)
            Task { @MainActor in
                let combo = await Rete.canonicalizza(
                    base: base,
                    keyCode: Int(ev.keyCode),
                    modificatori: mods,
                    caratteri: ev.charactersIgnoringModifiers ?? "")
                self.chiudi(conEsito: combo)
            }
            return nil                 // il tasto non prosegue
        }

        self.completamento = completamento
        finestra.beginSheet(f) { _ in }
    }

    private var completamento: ((String?) -> Void)?

    /// Chiude e avvisa **una volta sola**, comunque sia finita.
    ///
    /// Il ramo che conta e' l'annullamento: senza questo, il foglio sparirebbe
    /// e la pagina resterebbe ad aspettare una scorciatoia che non arriva.
    @objc private func chiudi(conEsito combo: String? = nil) {
        if let m = monitor { NSEvent.removeMonitor(m); monitor = nil }
        if let f = foglio { f.sheetParent?.endSheet(f); foglio = nil }
        let c = completamento
        completamento = nil
        c?(combo)
    }
}
```

E in `Rete`, il giro verso l'agent:

```swift
    static func canonicalizza(base: URL, keyCode: Int,
                              modificatori: [String],
                              caratteri: String) async -> String? {
        var r = URLRequest(url: base.appendingPathComponent("api/keys-canon"))
        r.httpMethod = "POST"
        r.setValue("application/json", forHTTPHeaderField: "Content-Type")
        r.httpBody = try? JSONSerialization.data(withJSONObject: [
            "keyCode": keyCode, "modifiers": modificatori, "chars": caratteri,
        ])
        guard let (dati, resp) = try? await URLSession.shared.data(for: r),
              (resp as? HTTPURLResponse)?.statusCode == 200,
              let o = try? JSONSerialization.jsonObject(with: dati)
                  as? [String: Any]
        else { return nil }
        return o["keys"] as? String
    }
```
